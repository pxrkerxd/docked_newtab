# 🌌 Docked (Glassmorphic New Tab Extension)

A lightweight, high-performance Chrome extension designed to replace the standard new tab page with an aesthetic, customizable glassmorphic workspace.

## ✨ Features

- **Draggable & Snapping Dock:** A floating macOS-style dock with smooth dragging, live glowing hover animations, and precise edge/center snapping.
- **Live Weather Widget:** Seamless integration with Open-Meteo for real-time temperature and weather conditions based on your city.
- **Dynamic Personalization:** Customizable greetings with your name, adjustable clock/greeting font sizes, and 24h/12h time formats.
- **Productivity To-Do List:** Clean built-in task manager with local storage persistence.
- **Custom Wallpapers & Themes:** Preset gradients, dark/light themes, custom image/video background uploads, and adjustable blur/darken filters.
- **Lightweight & Fast:** Built entirely with vanilla HTML, CSS, and modern JavaScript for minimal memory consumption.

## 🚀 Installation & Local Development

1. Clone or download this repository.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select your project folder.
